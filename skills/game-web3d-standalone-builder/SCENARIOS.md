# L2 用户视角场景验收清单 (SCENARIOS.md)

本清单用于验收 `game-web3d-standalone-builder` 产出的 Web 3D 独立游戏是否真正满足玩家端到端体验（覆盖主路径、触屏、断网、存档恢复、昼夜天气交接，以及机翼与工位引导）。

---

### 场景 1（正常流 · 开场叙事过渡与首关引导闭环）
- **用户操作**：首次打开独立 HTML，在纯净环绕标题页点击「开始任务」，观看（或按 `Space` 跳过）三幕式迫降苏醒过场，跟随脚下 3D 引路箭头采集废铁与赤铜，前往太阳能熔炼炉批量炼制板材，再到精密制造台合成动力核心装入飞船。
- **期望行为**：
  1. 标题页无左上/左下冗余任务面板遮挡；过场结束平滑过渡至跟随视角，无镜头瞬移或残留按键自动走位；
  2. DAG 导航优先引导采齐全部 4 废铁 + 4 赤铜后再指向熔炼炉，无中途折返跑；
  3. 打开熔炉/制造台时左半屏实时展示 3D 炉火/激光动画，安装核心后飞船舱内灯光与全息仪表立刻亮起，东侧区域屏障平滑降下。

### 场景 2（正常流 · 钻头探矿、喷气升空与终局返航）
- **用户操作**：推进至第 3 关合成【螺旋地质钻头】，按 `[V]` 释放声呐波定位地裂暗脉并按 `[E]` 钻探；推进至第 4 关合成【微重力喷气飞行翼】，按住 `[Space]` 飞上 `5.4m` 南侧孤峰校准反射塔架通光桥；完成第 5 关双能力采集、3 项绕船点检并登船发射。
- **期望行为**：
  1. 未持钻头时无法开采地裂暗脉并给出清晰提示；持钻头按 `[V]` 出现 3D 扩散波环与共鸣光圈，按 `[E]` 触发旋转钻地动作与泥石晶屑喷泉；
  2. 按住 `[Space]` 双翼展开喷出尾焰平滑升空，落回孤峰台面 `~1.7s` 内能量槽自动回满；高空飞越地面熔炉上方（高差 `> 2.8m`）不会误弹地面 `[E]` 交互框；
  3. 返航过场完整呈现点火升空 → 深空星海 → 降落母星翠绿草甸，弹出结算界面时背景持续保持母星实时 3D 画面。

### 场景 3（多端边界流 · 手机横竖屏多指并发与侧拉胶囊抽屉）
- **用户操作**：在手机竖屏（`390×844`）与横屏（`844×390`）触屏环境下进入游戏，左手拇指推虚拟摇杆移动、右手拇指长按「🚀 喷气」升空，同时用第三根手指在屏幕空白处滑动旋转视角，接着松开喷气键；点击顶部「👁 纯净视野」及左上角 `📋 第X关` 迷你胶囊。
- **期望行为**：
  1. 触屏环境下自动隐藏键盘键位条并剥离 `[E]/[Space]` 文本后缀；左、右、下常驻大面板默认收起为迷你胶囊，中央 3D 视野通透且所有 UI BoundingBox 零重叠；
  2. 三指并发互不抢夺，松开喷气键瞬间仅停止推进，左摇杆移动与第三指镜头旋转继续平滑生效；
  3. 点击「👁 纯净视野」立即隐藏顶部文字条、3D 悬浮招牌与闲置提示；点击 `📋 第X关` 胶囊可随时展开查看详情并一键 `◂ 收起`。

### 场景 4（安全边界流 · 完全断网离线运行与零外部请求）
- **用户操作**：开启浏览器 DevTools `Network` 面板并勾选 `Offline`（断网状态），加载本地 `dist/*.html` 进行采集、合成、切换画质、开关音效与通关操作。
- **期望行为**：
  1. `audit-standalone-html.mjs` 静态检查 0 外部标签/URL 泄露；
  2. 浏览器 `performance.getEntriesByType('resource')` 全程返回空数组 `[]`，控制台 `0` 报错，所有贴图、模型与音效均正常呈现。

### 场景 5（异常恢复流 · 熔炼队列中途强刷页面与无存储隐私模式）
- **用户操作**：
  - 子测试 A：投入 4 份矿石点击「批量 ×2」开始熔炼，在进度条走到 `40%` 时立即刷新页面并点击「继续已保存进度」；
  - 子测试 B：在禁用 `localStorage`（抛 `SecurityError`）的沙盒环境中启动并游玩。
- **期望行为**：
  1. 子测试 A 重新读档后，正在熔炼中的产出已安全折算进背包，绝不发生“扣了原矿却没给成品”的吞材料现象；
  2. 子测试 B 不抛未捕获异常，标题页温和提示“已启用当前会话内存模式”，可正常游玩至通关。

### 场景 6（异常恢复流 · 空中垂直落向悬崖边与切后台长挂机恢复）
- **用户操作**：飞到孤峰平台边缘半高处松开全部方向键垂直下落；随后将浏览器标签页切到后台静置 3 分钟再切回前台。
- **期望行为**：
  1. 无方向键垂直下落触碰孤峰侧壁时自动沿径向平滑推出，绝不卡入石柱内部；任何极端位置按 `U` 或设置中的「返回坠机营地」均可无损复位；
  2. 切后台期间环境风声与工坊蜂鸣自动静音挂起；切回前台首帧时间步长被安全钳制（`<= 0.05s`），角色原地平稳待命不发生穿墙瞬移。

### 场景 7（正常流 · 昼夜、三态天气与星夜返航交接）
- **用户操作**：在标题页停留超过 3 分钟再开始任务；进入第 1 关后把设置里的昼夜锁到「星夜」、天气锁到「沙尘暴」，再改回自动；完成通关后从星夜起飞，看家园降落，再选返回荒漠自由探索。
- **期望行为**：
  1. 标题停留不消耗第 1 关前 150 秒晴天保护，标题上不出现沙暴；点「开始任务」仍是晴朗上午的迫降；
  2. 星夜能看见银河与环带巨行星，Milo 打开前照灯，卤水池高光与行星同一方向；沙暴有风沙和风声，没有雨雪；
  3. 家园降落是白昼草甸和足够亮的主光；回到荒漠后若仍是星夜，环境反射立刻回到夜间探针，而不是白天沙漠反射。

### 场景 8（边界流 · 机翼、工作台镜头与制造队列引导）
- **用户操作**：走到星织号机翼旁修理，再把镜头压低绕翼飞行；打开营地熔炼炉；在精密制造台排入一个子件后立刻去看引导箭头；熔炼读到一半刷新页面。
- **期望行为**：
  1. 角色不能穿入机翼，喷气背包可以从翼上方飞过；镜头既不穿翼，也不会因为视线高于机翼而被拽到船头；
  2. 熔炼炉特写停在炉外，不进船体；
  3. 制造台队列中的子件把箭头指到精密制造台，文案是等待组装，不是熔炼炉；刷新后背包里已有折算产物，制作次数与该产物一致，矿点若仍在重生则不会立刻可采。
